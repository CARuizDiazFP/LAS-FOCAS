# PR Diario - 2026-06-17

## Resumen de Cambios

Se migró el ecosistema agéntico de `.github/` a reglas portables para IDE, manteniendo las fuentes originales sin cambios. También se consolidó el frontend Vue 3 con App Shell modular, rutas dedicadas para módulos operativos y limpieza del layout legacy del panel.

## Contexto y Alcance

- **Módulos afectados**: customizations de agentes, skills, prompts, documentación y frontend web Vue 3.
- **Objetivo**: habilitar autodescubrimiento local para Gemini/Codex IDE desde archivos versionados del repo.
- **Restricción encontrada**: `.codex/` está montado como solo lectura en esta sesión, por lo que las skills Codex se generaron en `.codex-skills/skills/` como fallback portable.

## Cambios Realizados

- `GEMINI.md`: índice raíz para cargar reglas Gemini/IDE junto con `AGENTS.md`.
- `.gemini/rules/`: 37 reglas generadas a partir de 17 skills, 13 agentes y 7 prompts.
- `.gemini/rules/assets/frontend-specs/`: copia de especificaciones JSON asociadas al frontend.
- `.codex-skills/skills/`: 17 skills Codex portables con frontmatter de descubrimiento, triggers, globs, comandos y referencias copiadas.
- `docs/Mate_y_Ruta.md`: corrección de `repo-updater` para indicar push a `dev`, no a `main`, y registro de la migración portable.
- `web/frontend/src/components/app-shell/AppShell.vue`: shell compartido con sidebar modular, controles fijos de perfil/configuración en el lateral y espacio `#dynamic-module-actions` para toolbars futuras.
- `web/frontend/src/router/index.ts`: rutas dedicadas para Infraestructura, Repetitividad, VLAN, FO y Ciena, con redirects de compatibilidad desde `/?tab=...`.
- `web/frontend/src/views/PanelView.vue`: Home reducido al chat principal, sin tabs legacy ni carga estática de módulos.
- `web/frontend/src/api/client.ts`, `useSession.ts`, `useSla.ts` y `useCiena.ts`: cliente HTTP/composables compartidos para normalizar CSRF, sesión y flujos de módulos.
- `docs/web.md`: documentación actualizada del App Shell, rutas Vue, tokens CSS y validación dev del frontend.

## Validaciones

- Se verificó que `.github/skills/`, `.github/agents/` y `.github/prompts/` no fueran modificados.
- Se validó el conteo de equivalentes generados para skills, agentes y prompts.
- Se compararon bloques `bash` originales contra destinos generados para asegurar preservación exacta.
- Se parseó el frontmatter YAML de las reglas generadas.
- Se compiló el frontend en el stack Dev con `docker compose -f deploy/docker-compose.dev.yml --env-file .env.dev build web`.
- Se recreó `lasfocasdev-web` con `docker compose -f deploy/docker-compose.dev.yml --env-file .env.dev up -d web` y quedó `healthy`.
- Se evitó `./Start --rebuild-frontend` porque el revisor automático lo bloqueó por usar flujo no-dev y tocar más stack del requerido.

## Riesgos y Pendientes

- Para usar autodescubrimiento Codex exactamente desde `.codex/skills/`, hay que mover o copiar `.codex-skills/skills/las-focas-*` a `.codex/skills/` cuando el entorno permita escritura en `.codex/`.
