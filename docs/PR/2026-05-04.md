# PR Diario — 2026-05-04

## Resumen

Completar la migración *strangler fig* del frontend web: eliminar toda la lógica Jinja2 y Vanilla JS restante, convertir el backend FastAPI en una API puramente REST que sirve el SPA compilado por Vite.

## Archivos modificados

### Backend (`web/`)

- **`web/app/main.py`** — Cambios principales:
  - Eliminadas rutas HTML (`GET /`, `GET /panel`, `GET /sla`, `GET /reports-history`, `GET /admin`, `GET /admin/usuarios`, `GET /admin/servicios`, `GET /admin/Servicios/Baneos`).
  - Reemplazadas rutas `GET /login` y `POST /login` por endpoints JSON: `GET /api/auth/session`, `POST /api/auth/login`, `POST /api/auth/logout`.
  - `GET /logout` convertido a redirección a `/` (backward compat; el SPA detecta sesión vacía).
  - Eliminados: `from fastapi.templating import Jinja2Templates`, `templates = Jinja2Templates(...)`, `STATIC_DIR`, `TEMPLATES_DIR` (HTML).
  - Añadidos: `DIST_DIR`, `SPA_INDEX`, mount de Vite assets en `/assets`.
  - Añadido `GET /api/reports/history` — JSON con lista de reportes (requiere auth).
  - Eliminado helper `_admin_shell_response()`.
  - Añadido catch-all `GET /{path:path}` como **última ruta** → sirve `frontend/dist/index.html`.

- **`web/Dockerfile`** — Multi-stage actualizado:
  - Eliminadas líneas `COPY web/templates` y `COPY web/static`.
  - `COPY --from=web-build /frontend/dist/assets /app/static/assets` → `COPY --from=web-build /frontend/dist /app/frontend/dist`.

### Directorios eliminados

- `web/templates/` (8 archivos HTML Jinja2: `admin.html`, `admin_shell.html`, `index.html`, `login.html`, `panel.html`, `reports.html`, `servicios_baneos.html`, `sla.html`).
- `web/static/` (3 archivos Vanilla JS/CSS: `panel.js`, `sla.js`, `styles.css`).

### Frontend SPA (`web/frontend/`)

- **`web/frontend/index.html`** — Entry point actualizado a `src/main.ts`.
- **`web/frontend/vite.config.ts`** — Simplificado: eliminado `rollupOptions.input` dual. Entrada única desde `index.html`.
- **`web/frontend/src/admin/components/AdminLayout.vue`** — `<slot>` → `<RouterView />`, logout SPA vía `POST /api/auth/logout`.

**Nuevos archivos creados:**
- `src/main.ts` — entry point unificado.
- `src/App.vue` — root `<RouterView />`.
- `src/router/index.ts` — rutas unificadas con navigation guard (sesión + rol admin).

- `src/composables/useSession.ts` — singleton de estado de sesión; setea `window.CSRF_TOKEN`.

- `src/components/PanelLayout.vue` — topbar con logout SPA.

## Impacto

- **-9 104 líneas** de código legacy (Jinja2 + Vanilla JS eliminados).
- **+240 líneas** netas de infraestructura REST + SPA.
- El backend `web` es ahora una API REST pura; sin dependencia de Jinja2Templates en producción.
- El SPA Vue 3 maneja todo el routing del lado cliente (Vue Router 4).
- Recarga de página en cualquier ruta SPA funciona correctamente gracias al catch-all.
