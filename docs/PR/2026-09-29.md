# PR 2026-09-29 — API v1: OAuth2 M2M + `GET /api/v1/servicios/{servicio_id}/botellas`

## Resumen de cambios

- **OAuth2 `client_credentials`** (`api/app/oauth.py`, `api/app/routes/v1/oauth.py`):
  - `POST /api/v1/oauth/token` emite un JWT HS256 de 7 días.
  - `require_oauth_token(*scopes)` valida firma, algoritmo, `aud`/`iss`/`exp`, cliente activo y scope efectivo, y expone el cliente en `request.state.oauth_client`.
  - Es una superficie separada de la API key interna.
- **Endpoint** `GET /api/v1/servicios/{servicio_id}/botellas` (`api/app/routes/v1/servicios.py`):
  - Resuelve el ID vigente o histórico (`core/services/servicio_botellas.py`).
  - Devuelve las botellas combinando tres fuentes (traza Cromo cacheada, ruta legada e inventario), sin llamar a Cromo en vivo, e informa `orden_fuente`.
- **Migración** `20260929_01`: tabla `app.api_clients` (modelo `db/models/api_clients.py`).
- **CLI** `scripts/api_clients.py`: `crear` / `listar` / `desactivar` / `rotar-secret`.
- **Secreto** `oauth_jwt_secret_v1` agregado al servicio `api` en los dos compose y a `scripts/setup_local_secrets.sh`.
- **Dependencia** `PyJWT==2.15.1` en `api/requirements.txt` y en el `requirements.txt` raíz (`pip-audit` limpio).
- **Docs**: `docs/api.md` (sección nueva), `docs/Seguridad.md`, `docs/db.md` y `docs/decisiones.md`.
