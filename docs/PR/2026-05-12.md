# PR / Release Notes — 2026-05-12

## 1. Resumen ejecutivo

Se consolidó el entorno operativo de LAS-FOCAS sobre una nueva VM Debian 13 con IP privada `172.18.208.162`, se retiró del despliegue estándar la dependencia a Ollama/local LLM por restricciones de hardware y se dejó lista la documentación para formalizar el merge de `dev` hacia `main` como nuevo hito estable de producción.

## 2. Cambios incluidos

1. Actualización de documentación técnica y operativa para reemplazar referencias a la IP obsoleta `192.168.241.28` por `172.18.208.162`.
2. Alineación de `README`, `docs/`, `AGENTS.md` y `docs/decisiones.md` con la política de proveedor LLM externo vía API.
3. Limpieza de `deploy/compose.yml`, `deploy/docker-compose.dev.yml` y `Start` para quitar dependencias operativas a `host.docker.internal:11434` y chequeos de Ollama que ya no representan la topología real.
4. Actualización de `deploy/env.sample` y `deploy/env.dev.sample` para reflejar el uso estándar de `openai` en producción y `heuristic` en dev, sin asumir un LLM local.
5. Exclusión explícita de dumps locales (`*.dump`, `backup_*.dump`) para evitar que `backup_prod.dump` u otros volcados entren al historial Git.

## 3. Validación operativa esperada

- `web` publicado en `http://172.18.208.162:8080`.
- `api` accesible en `http://localhost:8001/docs`.
- `nlp_intent` iniciado con `LLM_PROVIDER=openai` en producción y `OPENAI_API_KEY` presente.
- Entorno dev manteniendo `LLM_PROVIDER=heuristic` salvo pruebas específicas del flujo productivo.

## 4. Procedimiento sugerido de merge dev -> main

```bash
git checkout dev
git pull --ff-only origin dev

git checkout main
git pull --ff-only origin main

git merge --no-ff dev -m "merge(main): consolidar VM Debian 13, IP 172.18.208.162 y proveedor LLM por API"
git push origin main
```

Si se desea dejar trazabilidad adicional del hito en tag:

```bash
git tag -a release-2026-05-12-vm-migration -m "VM Debian 13, IP 172.18.208.162, proveedor LLM por API"
git push origin release-2026-05-12-vm-migration
```

## 5. Riesgos y pendientes

- El soporte heredado para `ollama` sigue presente en parte del código de `nlp_intent`, pero ya no forma parte del despliegue recomendado.
- Los archivos locales ignorados (`.env`, `.env.dev`) deben revisarse manualmente antes del merge final para evitar valores obsoletos fuera del control de Git.
- Si `backup_prod.dump` ya fue agregado al index local, debe eliminarse del staging antes del commit/merge (`git rm --cached backup_prod.dump`).
